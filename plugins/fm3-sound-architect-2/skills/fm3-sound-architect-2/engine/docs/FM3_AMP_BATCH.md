# FM3 juhendatud partiikoguja 0.29.17

Vajab Python 3 ja Node.js-i PATH-is (`python3 --version`, `node --version`).
Paki ZIP Downloads-kausta; uus kaust on FM3_AMP_BATCH_0.29.17.
Säilita Documents/FM3_AMP_SESSION — kasutatakse samu olemasolevaid tõendeid.

```bash
python3 ~/Downloads/FM3_AMP_BATCH_0.29.17/scripts/FM3_AMP_BATCH.py --session ~/Documents/FM3_AMP_SESSION --port /dev/cu.usbmodem211104 --firmware 13
```

1. Koguja kontrollib olemasolevad GET/SYX-paarid ja näitab järgmist puuduvat nelikut.
2. Ava FM3-Edit, vali samas testpresetis näidatud Amp A/B/C/D mudelid. Muud seaded säilita. Save/Store pole vaja.
3. Ekspordi praegune preset SYX-failiks; lohista fail Terminali küsimuse järele ja vajuta Enter.
4. Koguja kontrollib faili mudelivalikut, terviklust ja sama baasi. Seejärel sulge FM3-Edit ja Fractal-Bot, jäta seadme seisund samaks ning kirjuta `jah`.
5. Tehakse üks GET. Edu nõuab kontrollsummasid ja 576/576 sõna kattuvust. Järgmiseks näidatakse uut nelikut; ava FM3-Edit uuesti.
6. Korda omas tempos. Failitee küsimuse juures `q` lõpetab ja loob ühe ZIP-i Documents-kausta. Laadi see vestlusse. Pluginat uuendatakse kogu partii põhjal.

Jätkamiseks käivita sama käsk. Edenemine arvutatakse uuesti valideeritud failidest, mitte pelgalt varasemast staatusest. Kataloogis on 331 kirjet; 42 malli on juba kaasas. Failinimi ei määra mudelit. Viimases osalises nelikus jäta ülejäänud kanalid samaks.

Ainult ZIP-i tegemiseks, ilma seadmeühenduseta:
```bash
python3 ~/Downloads/FM3_AMP_BATCH_0.29.17/scripts/FM3_AMP_BATCH.py --session ~/Documents/FM3_AMP_SESSION --firmware 13 --export-only
```

Vale SYX peatub enne GET-i. GET/SYX erinevus või sama mudeli vastuolulised variandid peatavad edenemise; saada veateade ja vastava capture-kausta ZIP kontrollimiseks. Ära kustuta tõendeid ega muuda raportite staatuseid. Ebaõnnestunud või katkestatud päringuid ei loeta valmiks. Ctrl-C järel säilivad juba kirjutatud failid; pooleli päring säilitab võimalusel toorvastuse. Automaatset korduspäringut ei tehta. ZIP sisaldab sessiooni varasemaid capture.json/donor.syx tõendeid, mitte kasutaja muid faile.

Ohutus ja piirid: mudelid valib kasutaja; SET, Save/Store ja automaatset presetivahetust pole. Eraldi GET jääb igale nelikule nõutuks. Tundmatu dekooderivastendus peatab kontrolli, mitte ei kirjuta oletuslikku malli. Genereeritud kombinatsioonide heli/CPU/riistvarakinnitus on eraldi töö.
