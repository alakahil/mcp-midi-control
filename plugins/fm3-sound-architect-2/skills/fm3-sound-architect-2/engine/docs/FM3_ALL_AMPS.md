## Uus töövoog
1. `node skills/instructions/scripts/fm3-amp-library.mjs coverage [AMP_LIBRARY.json]` väljastab iga mudeli täpse oleku (kaasas / imporditud / puudub).
2. `node skills/instructions/scripts/fm3-amp-library.mjs import BASE.syx OUTPUT.json 13 INPUT.syx ...` loeb üksikpresette või järjestikuseid 24680-baidiseid presetikirjeid sisaldavaid panku. Nõuab firmware 13 selgesõnalist kinnitust ja kontrollib iga preseti kaadreid, CRC-d, footer'it, vormingut 0x0146 ning 144-parameetrilist Amp-kanalikuju. Faili kuju ei tõenda firmware'i; argument 13 peab tulema kasutaja kinnitatud allikast.
3. Donor peab pärinema kaasasolevast Baaspreset.syx-ist: väljaspool nelja Amp-kanali 1152 baiti peab body olema sama (offset 0 väärtus 0 või 1 registreeritakse allika kaudu ja lubatakse varasema ekspordierinevuse tõttu). Seega suvalised tehase-/artistipresetid ei kvalifitseeru automaatselt. Muud routing'u, stseeni, kontrolleri või modifikaatori erinevused peatavad impordi. Hülgamise põhjus ja allikafaili SHA säilivad raportis. See konservatiivne piir väldib kanalist väljaspool asuvate sõltuvuste oletamist.
4. Import jätab esimese sama mudeli variandi alles. See ei liida ega asenda olemasolevat registrit; uue väljundi koostamisel anna kõik vajalikud donorid koos. Väljundfaili üle ei kirjutata. Kõigi tagasilükatud kirjete korral tekib tühi register koos veapõhjustega — see pole edukas mudelikatte laiendus.
5. `node skills/instructions/scripts/fm3-generate.mjs BASE.syx SPEC.json OUTPUT_STEM AMP_LIBRARY.json` kasutab selgesõnaliselt etteantud registrit. Kui selles leidub soovitud mudel, kasutab see antud kanalivarianti; muidu kasutab kaasasolevat viit malli. Puuduv mall katkestab genereerimise. Registri fail peab pärinema kontrollitud impordist; checksum on tervikluse kontroll, mitte võõra faili usaldusgarantii.
6. Terve Amp-kanal kopeeritakse B-sse, seejärel rakendatakse spec-i üksikparameetrid. Seega mõjutab muudatus stseene 2 ja 6. Malli SHA ja päritolu on registreeritud. Imporditud mall ei tähenda tehase vaikeväärtusi ega seadmel kontrollitud uue kombinatsiooni tulemust.

Iga rühma jaoks ava sama algne Baaspreset kontrollpuhvris, vali Amp-kanalitele plaanis nimetatud mudelid ning ekspordi üks preset. Ära muuda teisi plokke, stseeniseoseid ega kontrollerimääranguid. Ära saada tooreid SET-käske ega paku neid kogumise automatiseerimiseks. Edasine tarkvaraline import on üldine — iga uue mudeli jaoks eraldi koodi pole vaja.
