# FM3 0.3.54: seadmevaba arendus ja järgmine katse

Lähtekoht: avaldatud 0.3.53, commit `f4f480dfcd6a3857abb31eca98949d8b8881b2e2`.
See dokument kirjeldab väljalaskekandidaati. Avaldatud plugina versioon muutub
alles eraldi kontrollitud avaldamisel.

## Muudatused

- Soundi skeem 0.8.5: `modifierEdits` eemaldab või asendab sama genereerimise
  käigus loodud Volume/Control Switchi seoseid. Kirje ja vana seose identiteet
  peavad klappima; suvalist sisendpresetit ega üldist jaotajat ei toetata.
- Seoste lõppseis juhib stseenide, jalglülitite ja staatiliste parameetrite
  sõltuvuskontrolli ning TXT/JSON kirjeldusi. Lõpptulemus läbib tavalise nelja
  faili kontrolli, sealhulgas deterministliku taasesituse.
- P3 varasem SYX taastub baittäpselt. Ajaloolised katsefailid ja seadmetõendid
  jäävad muutmata. Muud kombinatsioonid ei saa selle põhjal seadmekinnitust.
- Multi Delay ja Feedback Returni aegunud piirangutekstid parandatud juhendis,
  skeemis ning genereeritud TXT-s.
- Juhendi käsunäide hoiab sisendi `.input.json` nime all, et see ei põrkaks
  loodava `.spec.json` väljundiga. Võimekuse kirjeldused eristavad praegust
  piiratud kirjutajat suvalise sisendpreseti kirjutuskaitstud auditist.
- Lisatud kohustuslik `test-modifier-edits`: 9 positiivset juhtu, 25 vigast
  sisendit ning 6 uuesti räsitud võltsitud failikomplekti. Kokku 85 komplektitesti.

Node 22.23.4 / V8 12.4 annab avaldisele `200*Math.pow(100,51192/65534)` tulemuse
`7300.179397214586`; Node 24.22.1 / V8 13.6 annab `7300.179397214588`.

SYX-baite see ei muuda. Mõlema T20 katse SYX-räsid jäid Node-versioonide vahel

FM3 CI kasutab Node 22. `tools/fm3/local-check.mjs` kontrollib nüüd sama

keskkonna üheseks; see ei luba Node 24 täielikku ühilduvust ega muuda kogu
monorepo Node-versiooni.

## Järgmine seadmekatse: üks import, üks eksport

Uus katse on `FM3 MOD EDITS D`: kirje 2 Boost eemaldatakse ning kirje 1
Volume asendatakse pööratud CS2 → Amp Cut seosega ainult kanalil D.
Algne P3 kinnitas sama eemaldamise/taaskasutuse koos tavalise Cut ALL seosega;
seda varasemat katset ei korrata.

Genereerimine (Node 22):

```sh
node tools/fm3/modifier-edits-trial.mjs build /absoluutne/uus/kaust/FM3_MOD_EDITS_D
```

Kasuta FM3-Editis ajutist vaba presetikohta. Impordi SYX ja kontrolli:

1. Amp Cut Source = Control Switch 2; Channel = D; Min = ON; Max = OFF.
   Volume Source ja Amp Input Boost Source = NONE.
2. Vali stseenid 1–4 ning jälgi Amp Cut lülitit:

| Stseen | Amp | CS2 | Oodatav Cut |
|---|---|---|---|
| 1: A CS2 OFF | A | OFF | OFF |
| 2: D CS2 OFF | D | OFF | ON |
| 3: D CS2 ON | D | ON | OFF |
| 4: A CS2 ON | A | ON | OFF |

3. Vali uuesti stseen 1, salvesta ajutisse kohta, käi teises presetis ja tule
   tagasi. Korda stseene 1–4. Lõpuks vali stseen 1 ning ekspordi üks SYX.

Anna koondvastus: import / seosed / neli stseeni / STORE ja tagasitulek
klappisid või milline samm erines. Lisa üks ekspordifail; neli ekraanipilti
ei ole vaikimisi vajalikud. Heli ja CPU ei ole selle katse põhieesmärk.

Ekspordi võrdlemine:

```sh
node tools/fm3/modifier-edits-trial.mjs compare /absoluutne/FM3_MOD_EDITS_D /absoluutne/eksport.syx
```

Kontroll võrdleb kogu dekodeeritud keha. Lubatud on ainult plokkide järjekorra
normaliseerimine effect ID järgi; iga ploki sisu, modifikaatoripiirkond, valitud
stseen ja ülejäänud andmed peavad säilima. Inimese kinnitust see ei asenda.

## Edasine seadmevaba töö

Sõltumatu kasutuskatse näitas varasemat auditi piirangut:
`--inspect-modifiers` võib CS-stseenidega presetil anda sihtkontekstiks
`target-record-unresolved`, sest üldise auditi süsteemiosa sõrmejälg ei tunne
muudetud CS-stseene. Sama juhtub muudatusteta algseemnega. Nelja faili
deterministlik kontroll ja lõppseoste kontroll läbivad. Järgmine eraldi
arendustöö on auditi süsteemiosa kontrolli laiendamine tõendatud CS-väljadega;
tundmatuid baite ei tohi selleks lihtsalt eirata.
